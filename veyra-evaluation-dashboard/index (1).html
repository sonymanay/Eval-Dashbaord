Operating intelligence for TPM programs: from scattered signals to governed action.

How the release gate works

1CaptureFreeze dataset, model/config version, source snapshot, and trace envelope.
2ScoreRun deterministic checks, golden-set metrics, tool tests, and model judges.
3DiagnoseAttribute every miss to Sense, Decide, Synthesize, Deliver, or Govern.
4GateShip only if critical recall and F1 bars pass and all trust controls are green.
Eval does not stop at release. The release gate decides whether a version ships; post-release evaluation decides whether it can still be trusted.

Alert when…

Trust gates are binary: one failure is enough to alert.
  • Critical-class recall drops
  • A trust gate fails once
  • The input distribution shifts materially
  • Citation source health degrades
  • Human override clusters emerge
Every alert creates a diagnosable case and a candidate for dataset rehydration.

What feeds back into the golden set

Production failures are rehydrated so the same miss cannot recur silently.
Missed signalsFalse alarmsHuman overridesBad routesUnsupported claimsTool failuresNew program patterns
Dataset strategy: Golden (SME-curated, 100–300 cases) → Synthetic (200–1,000 coverage cases) → Production (continuous, rehydrated failures). Versioned, de-identified and source-provenanced.

Closed learning loop

1MonitorWatch drift, overrides, misses, false alarms, and outcome KPIs.
2RehydrateAdd new and failed patterns to the golden or synthetic set.
3ImproveChange prompts, rules, routing, tools, or policy with a versioned hypothesis.
4RegressReplay the full evidence suite before the next controlled rollout.
Why continuous: a single scoring run is a snapshot. Only a nightly cadence over several weeks shows whether accuracy holds, and the feedback loop needs at least two weeks of real outcome data before it can be judged.

01 · SENSE

Did VEYRA detect the right signal?

Measure precision, recall, F1, source coverage, duplicate rate, detection latency, and source lineage. Segment by priority and source.

For this dataset, the golden truth is shouldSurface.
02 · DECIDE

Did VEYRA classify and route correctly?

Run the nine-rule deterministic suite, validate lifecycle transitions, and measure joint escalation-target plus SLA accuracy.

Rules are exact checks; AI judgment handles semantic evidence the structured fields do not capture.
03 · SYNTHESIZE

Is the leadership narrative trustworthy?

Evaluate groundedness, completeness, relevance, concision, citation integrity, and unsupported-claim rate.

A good classification can still produce a bad brief—score the stages separately.
04 · DELIVER + GOVERN

Was the action safe and accountable?

Require approval, authorization, valid tool arguments, state integrity, scoped memory, visible errors, and a complete audit trail.

Trust gates are binary: zero unapproved write-backs and zero successful prompt injections.
